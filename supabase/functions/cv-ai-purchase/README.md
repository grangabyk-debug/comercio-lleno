# cv-ai-purchase

La implementación activa de esta función está desplegada en el proyecto Supabase de Comercio Lleno con el slug `cv-ai-purchase`.

Responsabilidades:

- crear preferencias de Mercado Pago para CV Pro y Búsqueda Activa;
- asociar la orden a la sesión central de CV IA;
- validar token opaco de la orden;
- verificar estado, importe y moneda del pago contra Mercado Pago;
- procesar webhooks;
- nunca habilitar el servicio desde el navegador sin verificación de servidor.

Precios de lanzamiento: CV Pro ARS 8.900 y Búsqueda Activa ARS 12.900.
