# Búsqueda Activa Pro+ — investigación de producto (19/08/2026)

## Benchmark confirmado
- Huntr: tracker de postulaciones, documentos, contactos, mapa/métricas, matching y scoring; Pro USD 40/mes. Fuente: https://help.huntr.co/en/articles/10714568-plan-types-and-pricing y https://help.huntr.co/en/articles/9883324-job-tracker
- IBM SkillsBuild: formación 100% gratuita, cursos breves y credenciales digitales de IBM/Credly; catálogo con filtros <1h y 1–3h. Fuente: https://skillsbuild.org/es y https://skillsbuild.org/es/digital-credentials
- Microsoft Learn: capacitación gratuita; credenciales verificadas y Applied Skills orientadas a escenarios reales, compartibles. Fuente: https://learn.microsoft.com/en-us/training/support/faq y https://learn.microsoft.com/en-us/credentials/

## Dirección para Postulá Mejor
El plan de 30 días debe vender acompañamiento de búsqueda, no sólo un CV. Núcleo recomendado:
1. Hoy: próxima mejor acción, días restantes, oportunidades activas y tareas vencidas.
2. Nueva oportunidad guiada: pegar oferta → detectar requisitos → elegir CV base → adaptar → checklist antes de enviar → registrar estado.
3. Pipeline: Guardada / Preparando / Enviada / Entrevista / Oferta / Cerrada, con fecha, fuente y próximo seguimiento.
4. Preparación: preguntas probables, historias STAR basadas sólo en hechos reales del usuario, checklist de entrevista y follow-up.
5. Formación: catálogo curado externo de IBM SkillsBuild y Microsoft Learn. Sólo permitir “Agregar al CV” cuando el usuario marque finalizado y aporte credencial/enlace cuando exista.
6. Métricas: postulaciones, respuestas, entrevistas, tasa de respuesta, días desde último movimiento y fuente con mejor respuesta.
7. Buscadores: accesos profundos a LinkedIn/Indeed/Google Jobs/Bumeran/Zonajobs; evitar prometer integración oficial donde no exista API pública sencilla.
8. Integración futura: evaluar Adzuna/Jooble como agregadores por API sólo después de validar cobertura argentina, términos, costos y atribución. No bloquear el MVP por una API de empleos.

## Instructivo “Nueva oportunidad”
- Pegá el aviso o descripción completa.
- Indicá empresa y puesto si no se detectan.
- Postulá Mejor compara el aviso con el CV sin inventar experiencia.
- Elegí qué versión del CV adaptar y revisá cambios.
- Descargá el CV final y registrá dónde/cuándo postulaste.
- El sistema crea el próximo seguimiento y conserva el historial de esa oportunidad.

## Retención 30 días
- Día 1: objetivo + CV base + primera oportunidad.
- Días 2–7: cadencia de postulaciones de calidad y corrección de brechas.
- Semanas 2–3: entrevistas, follow-ups y formación corta.
- Últimos 5 días: resumen de progreso + renovación contextual basada en oportunidades activas y resultados; no cobrar automáticamente sin consentimiento explícito.
