# Postulá Mejor mobile navigation v46

- Invitados: no se muestra la barra completa de cuenta. Sólo aparece un botón compacto de menú con accesos públicos, iniciar sesión y registro.
- Sesión iniciada: aparece un dock compacto con accesos principales y un menú de cuenta.
- El menú de cuenta incluye mensajes, postulaciones/candidatos, configuración y cierre de sesión.
- El cierre de sesión también queda disponible en Nexo móvil para cuentas de empresa.
- Ayuda se reduce en móvil a un botón circular con `?`, separado por encima del dock.
